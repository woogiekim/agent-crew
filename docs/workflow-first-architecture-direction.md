# Establish workflow-first architecture direction

This document prevents the project from becoming model-centric or
agent-count-centric.

The primary system value must remain:

```text
Workflow Reliability
```

rather than:
- increasing agent count
- adding more prompts
- maximizing model complexity

## Strategic Direction

The architecture must prioritize:
- workflow continuity
- checkpoint/recovery
- state durability
- execution orchestration
- deterministic transitions
- operational resilience

## Anti-Goals

The project should avoid evolving into:
- autonomous chaos systems
- uncontrolled recursive agents
- prompt spaghetti architecture
- stateless execution pipelines
- model-dependent workflows

## Key Principle

```text
Stable workflow systems outlive model generations.
```

Workflow durability is the long-term moat.
