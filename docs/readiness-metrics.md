# Commercial Readiness Metrics

Commercial go/no-go decisions use five metrics generated by
`core/scripts/readiness-metrics.py`.

## Metrics

| Metric | Meaning | Direction |
|---|---|---|
| `consecutive_clean_full_validation_runs` | Number of latest validation reports that passed without a failed full run between them. | Higher is better |
| `host_bridge_completion_rate` | Hosted tasks completed automatically by the host bridge divided by total tasks. | Higher is better |
| `human_intervention_rate` | Manual repairs or operator interventions divided by total tasks. | Lower is better |
| `retry_rate` | Retry count divided by total tasks under realistic workloads. | Lower is better |
| `task_success_rate` | Successful tasks divided by total tasks. | Higher is better |

## Evidence Inputs

Validation reports come from:

```bash
python3 core/scripts/phase-1-validation.py --output dist/phase-1-validation.json
python3 core/scripts/phase-2-validation.py --output dist/phase-2-validation.json
```

Hosted workload evidence can be one or more JSON files with:

```json
{
  "tasks": 10,
  "successes": 10,
  "host_bridge_completed": 10,
  "manual_repairs": 0,
  "retries": 0
}
```

Thresholds are intentionally supplied as a JSON file so commercial targets can
be raised without changing the aggregator:

```json
{
  "consecutive_clean_full_validation_runs": 3,
  "host_bridge_completion_rate": 0.95,
  "human_intervention_rate": 0.02,
  "retry_rate": 0.1,
  "task_success_rate": 0.95
}
```

## Running

```bash
python3 core/scripts/readiness-metrics.py \
  --validation-report dist/phase-1-validation.json \
  --validation-report dist/phase-2-validation.json \
  --workload-evidence dist/hosted-codex.json \
  --workload-evidence dist/hosted-claude.json \
  --workload-evidence dist/hosted-generic.json \
  --thresholds dist/readiness-thresholds.json \
  --output dist/readiness-metrics.json
```

If hosted evidence or thresholds are absent, affected metrics are reported as
`unmeasured` and the run fails. That is the expected result before external
hosted validation has been approved and completed.
